
# METRO

Digital Ordering & Batch Delivery Platform for
Metro Frozen Food Surabaya.

## Overview

METRO is a web-based ordering and delivery management
platform developed as part of the Asah 2026 Capstone Project.

## Tech Stack

- Frontend: React, Vite, Tailwind CSS
- Backend: Node.js, Express.js
- Database: PostgreSQL (Planned)
- ORM: Prisma (Planned)
- Data Science: Python
- AI Engineering: Python / AI API

## Project Structure

- client/ — Customer and Admin Web Application
- server/ — REST API and Business Logic
- data-science/ — Batch Delivery and Cost Estimation
- ai-service/ — AI Features
- docs/ — Technical Documentation

## Local Development

### Frontend

cd client
npm install
npm run dev

### Backend

cd server
npm install
npm run dev
